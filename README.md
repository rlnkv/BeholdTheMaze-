BeholdTheMaze- 🌀
Welcome to BeholdTheMaze- — where friendships are tested, siblings are forced to work together, and a innocent 42 school project spiraled joyfully out of control.

What started as a standard academic maze generator ("A-Maze-Ing") somehow evolved into a full-blown cooperative labyrinth challenge built specifically so two kids (not random one - my sons) could team up, argue over directions, and try to beat the game together.

🧭 What's Inside the Box? (Main Menu)
When you fire up the game, you'll be greeted by a Main Menu with three distinct choices:

Generate Random Maze: A nostalgic nod to the original 42 project. Generates random sized maze with start and finish points and only one path connecting them.

Create Custom Maze: Same stuff, but maybe you want to influence on some parameters of the maze.

Challenge Mode (The Crown Jewel): 6 unique levels packed with different challenges. They are genuinely fun—go ahead, try them out and see if the team survives!

🎮 Controls
Teamwork makes the dream work, but only if you don't mash the wrong keys:

Player 1: Arrow Keys

Player 2: WASD

(Pro-tip: Deciding who gets the WASD keys is the first real challenge of the game - a lot of tears spilt there).
